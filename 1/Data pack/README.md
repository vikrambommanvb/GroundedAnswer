### About the corpus

The manual is a single Markdown file of twelve Parts. Every provision is numbered in the form `§4.3.2`, meaning Part 4, section 3, paragraph 2. That numbering is stable and is what your citations should refer to.

It is written the way a real manual of this kind is written: by different hands, over years, with sections revised in place and the surrounding text not always brought into line. Read it as a caseworker would have to — it is not a clean document and it is not supposed to be.

### Working with it

The file is plain Markdown with no images and no tables beyond two small ones. Chunk it however you like; the section numbering gives you a natural boundary if you want one.

A note on scope: the manual is the only authority. If something is not in it, it is not policy, however reasonable it might sound. An answer that draws on general knowledge of how benefits programs usually work — rather than on this text — is a wrong answer even when it happens to be sensible.
